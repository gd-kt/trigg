# Trigg

<div align="center">
    <img src="https://github.com/gd-kt/docs/raw/main/docs/public/logos/trigg/logo_title.png" height=35% width=35% alt="trigg logo">
</div>

Trigg is a [spwn](https://github.com/Spu7Nix/SPWN-language) inspired kotlin DSL.
It is dependent on [gd.kt](https://github.com/gd-kt/gd.kt).

It allows, like [spwn](https://github.com/Spu7Nix/SPWN-language), to make complex trigger stuff, but in a way where they are abstracted away.
